# Contributing

Thanks for helping with QuickK.

## Pull requests from forks

If you open a PR from a **fork** of this repository, GitHub often **does not run Actions** on your branch until a maintainer approves it. On the PR, check the **Checks** tab; if workflows are waiting, a maintainer will use **Approve and run workflows** (or **Run workflow** on the pending jobs).

We try to approve the first run quickly so you can see compile, test, and any security workflow results before merge.

Docs: [Approving workflow runs from public forks](https://docs.github.com/en/actions/managing-workflow-runs/approving-workflow-runs-from-public-forks)
